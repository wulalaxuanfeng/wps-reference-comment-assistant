# WPS 参考文献批注助手

为 WPS 文字正文中的参考文献引用添加批注，查看文末对应的完整文献。适合已经插入编号引用、希望在审阅时方便查看文献内容的论文。

当前版本：**v0.1.2**。使用 JavaScript 开发，通过 WPS 原生批注接口操作当前文档。

## 功能

- 支持单条引用：`[1]`、`[12]`。
- 支持组合和连续引用：`[23,26]`、`[27-29]`、`[38,42-44]`、`[45,46]`。
- 一组引用生成一条批注，按顺序列出完整文献，重复编号去重。
- 重复生成跳过已有助手批注；提供刷新和清除功能。
- 保留引用文字和原有上标，不重写正文或更新文献编号。
- 保留普通批注、导师批注；助手批注含他人回复时也会保留。
- 文献数据来自手动选中的文末列表，不需要 Zotero 或网络检索。

## 环境要求

- Windows，已安装支持 JavaScript 加载项功能的 WPS 文字。
- Node.js 18 或以上，可从 [Node.js 官网](https://nodejs.org/)获取。
- 已在 Windows WPS **12.1.0.28505** 上验证；其他版本需要自行测试，不能保证所有版本和发行版都兼容。

这是 WPS 文字加载项，不是 Microsoft Word 插件，也不是独立 EXE。日常启动不需要安装 npm 依赖；Node.js 用于提供本地加载服务。

## 下载与安装

1. 在仓库点击 **Code → Download ZIP**，解压到固定目录；也可以使用 Git 克隆仓库。
2. 安装 Node.js。如果刚安装，请重新打开终端或重新运行启动文件，让系统识别 Node.js。
3. 双击 **启动参考文献助手.cmd**，启动本地服务并配置加载项。
4. 首次安装后，保存正在编辑的文档，自行完全退出 WPS，再重新打开。
5. 顶部出现 **参考文献助手** 选项卡，包含生成、刷新、清除三个按钮。

目录应保持完整，不要只复制或移动 `.cmd` 文件。安装脚本不会自动关闭 WPS 或替你保存论文。

## 使用

### 生成批注

1. 打开论文，确认文末文献编号是实际文字，例如 `[1] 作者. 题名…`。
2. 手动选中从第一条文献编号开始，到最后一条文献末尾的**完整文献列表**。可以包含独立的“参考文献”或“References”标题，不能包含正文、致谢或附录。
3. 点击 **参考文献助手 → 生成文献批注**。
4. 在 WPS“审阅”中打开批注显示，查看对应文献。
5. 保存文档。建议使用 `.docx` 保存和验证批注持久化。

例如，正文 `[38,42-44]` 对应一条批注，其中包含第 38、42、43、44 条文献。

助手只扫描选区之前的主正文。文中某个 `[数字]` 如果不是文献引用，但编号在文献列表中存在，也可能添加批注；可以手动删除。再次生成时仍可能重新添加，目前没有永久排除列表。

### 刷新与清除

- **刷新文献批注**：文献内容或编号改变后，重新选择完整列表，再点击刷新。先校验列表、生成新批注，再清理旧助手批注；添加失败时尝试回滚本次新批注并保留旧批注。
- **清除文献批注**：无需选择文献列表，只清除可识别为本助手生成且没有他人回复的批注。

含有他人回复的助手批注会保留，刷新时也不替换其内容，请自行处理。

## 支持范围与限制

- 文献条目必须以实际文字 `[数字]` 开头，编号可以不连续；重复编号和空条目会停止处理。
- 文献条目可以有自动换行、手动换行或多个段落。
- 引用支持英文/中文逗号、空格和常见横线；不支持全角方括号。
- 不读取只存在于自动列表编号、没有出现在正文文字中的编号。
- 不扫描脚注、尾注、页眉、文本框，也不扫描文献选区之后的内容。
- 组合引用部分编号缺失时，列出已找到的文献并提示缺失编号；整组都找不到时跳过。
- 用户需确保选中了最后一条文献的全部内容，程序不能判断条目是否被选全。

“读取文献”是文末条目数，“识别引用”是引用位置数，“新增批注”是本次创建数。一组包含多篇文献也只生成一条批注；重复引用、跳过已有批注等也会使这些数字不同。

## 本地服务与隐私

当前版本通过 `http://127.0.0.1:38991/` 向 WPS 提供加载项文件，只监听本机回环地址。`127.0.0.1` 是自己的电脑，不是外网网站。

服务只公开指定的加载项文件、健康检查和运行状态上报接口，不提供任意目录或论文下载。文献解析和批注操作在 WPS 内部执行，不上传论文到外网；运行状态与错误信息记录在本地 `logs/`。

- 电脑重启后，需要再次双击启动文件。
- 浏览器标签页可以关闭；后台服务需要在加载助手时可用。
- 已生成的批注属于文档内容，保存后不会因服务关闭而消失。
- 当前版本没有开机启动、点击按钮自动启动服务或运行完自动关闭服务的功能。

安装脚本只增加或更新 `%APPDATA%\kingsoft\wps\jsaddons\publish.xml` 中本助手的条目，并备份原配置。不修改 WPS 的 `oem.ini`、信任配置或安装目录。

## 更新、卸载与排查

- **更新**：替换项目文件后双击 **更新参考文献助手.cmd**。结果弹窗应显示当前版本；如仍使用旧代码，保存文档、完全退出 WPS，再重新打开。
- **卸载**：双击 **卸载参考文献助手.cmd**，移除助手加载配置并停止本项目后台服务。文档批注保留；如需删除，先在 WPS 中使用清除按钮。
- **选项卡不出现**：确认 Node.js 可用，查看 `logs/server-error.log`，在浏览器检查 `http://127.0.0.1:38991/health` 是否返回助手状态，然后完全重启 WPS。
- **引用位置发生变化**：先确认结果弹窗版本，更新并重新加载。如果仍发生，请提供 WPS 版本和人工编写的复现样例。
- **信任提示**：检查来源是否为本机助手地址 `http://127.0.0.1:38991`，按 WPS 正常流程处理。
- **端口被占用**：启动脚本会报告冲突，请检查占用来源，不要随意结束其他程序。

## 测试与开发

自动化测试使用 Node.js 内置测试框架，不需要启动 WPS，也无需先安装依赖：

```powershell
npm test
npm run build
```

目前包含 17 项测试，覆盖文献解析、组合引用、重复生成、刷新回滚、批注识别、回复保留及原生引用范围处理。

人工编写的测试文档位于 `examples/`：

- `测试论文.rtf`：选中两条文献后，应生成 4 条批注；重复生成新增 0 条；未知编号和选区之后的附录不处理。
- `组合引用测试.rtf`：包含 4 处组合引用和 50 条文献，应生成 4 条批注。

可以在测试文档中手动添加一条普通批注，再验证刷新、清除后仍保留。批注保存重开测试请使用另存的 `.docx` 副本。

开发调试工具需要依赖：

```powershell
npm ci
npm run debug
```

WPS 加载项调试器可用 **Alt + F12** 打开，关闭消息框后查看控制台中的 `WraLastResult` 和错误信息。`调试参考文献助手.cmd` 请求额外的 WPS 调试端口，已有进程可能忽略启动参数。

`scripts/wps-runtime-test.cjs` 提供实际加载项环境下的诊断和独立样例测试，需要已加载助手及 WPS 官方本地 RPC 服务；它不是安装步骤。`tests/live-host.js` 和 `tests/live-wps.ps1` 提供 Windows COM 实机检查，需具备 WPS COM 接口。一般使用者先按人工样例步骤验证即可。

### 代码结构

| 文件 | 用途 |
|---|---|
| `js/core.js` | 文献、引用格式解析和助手批注识别 |
| `js/host.js` | WPS 选区、原生查找范围、批注增删 |
| `js/ribbon.js` | 按钮回调和执行结果提示 |
| `ribbon.xml` | 功能区按钮配置 |
| `manifest.xml`、`index.html`、`main.js` | 加载项声明与入口 |
| `scripts/start.ps1`、`scripts/server.cjs` | 安装配置与本地加载服务 |
| `scripts/uninstall.ps1` | 卸载配置和本项目服务 |
| `tests/`、`examples/` | 自动化测试、实机检查和人工样例 |

助手通过固定批注作者和缩写识别自己的批注；无法设置元数据时使用批注开头的兼容标识。请不要把普通批注的作者和缩写手动改成助手使用的值。
